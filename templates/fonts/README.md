# Fonts

Place `bold.ttf` here. The pipeline falls back to PIL's built-in bitmap font if missing,
but text quality will be significantly worse.

## Recommended free fonts

| Font | URL | Licence |
|------|-----|---------|
| Bebas Neue Bold | fonts.google.com/specimen/Bebas+Neue | OFL |
| Montserrat ExtraBold | fonts.google.com/specimen/Montserrat | OFL |
| Anton | fonts.google.com/specimen/Anton | OFL |

Download, rename to `bold.ttf`, and place here.
